# karesansui-architecture

## Overview

Design philosophy documentation repository. "Karesansui" (枯山水, Japanese dry rock garden) represents an approach to software design: not efficiency-driven minimalism, but investing deeply in simplicity. Documentation-only — no code, no scripts, no build system.

## Key Constraints

1. Documentation only — do not add code, scripts, or configuration files.
2. Preserve CC BY 4.0 license attribution — do not remove or modify license notices.
3. Maintain design philosophy coherence — new content must align with the existing karesansui metaphor and principles.
